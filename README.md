# Supreeth Chittaluri — Portfolio

Version 1 of Supreeth Chittaluri’s personal software engineering portfolio.

Built with Next.js, TypeScript, and Tailwind CSS. The page stays intentionally lightweight: project tiles use native HTML details/summary interactions, so the work remains accessible without client-side state.

## Local development

```bash
npm install
npm run dev
```
